= Confium Specs by Product
:author: Confium Project
:toc: macro
:toclevels: 3

Confium is organized into 6 products. This index lists every spec under its primary product. Mode 1/2/3 terminology is deprecated in favor of product names; specs that still reference modes are retained for historical context.

== Threshold

T-of-N distributed signing — CMP20, GG18, FROST, MuSig, BLS.

* link:22-threshold-session.adoc[Threshold Session] — session lifecycle, party registry, message dispatch
* link:23-async-coordinator.adoc[Async Coordinator] — multi-round orchestration service
* link:24-share-reshare.adoc[Share & Reshare] — Herzberg refresh, T/N changes without re-keying
* link:51-frost-p256.adoc[FROST over P-256] — 2-round threshold ECDSA with Feldman VSS
* link:54-elgamal-p256.adoc[Threshold ElGamal over P-256] — threshold encryption
* link:70-cmp20.adoc[CMP20 Threshold ECDSA] *(draft)* — 3-round ECDSA with Paillier MtA
* link:71-gg18.adoc[GG18 Threshold ECDSA] *(draft)* — 4-round ECDSA (legacy; prefer CMP20)
* link:72-frost-ed25519.adoc[FROST over Ed25519] *(draft)* — 2-round threshold EdDSA

== Adding a new spec

1. Pick the next free number in the relevant product range (30s for privacy, 60s for verify, etc.).
2. Copy the structure of an existing spec.
3. Set the `:product:` attribute in the header.
4. Add a link entry to this index.
5. Set status to `:status: draft` until reviewed.
